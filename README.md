# Data Structure

C++ exercises for the Data Structure course.

| Folder | Topics |
|--------|--------|
| [q1](q1/) | STL basics: vector, map, set, pair, sorting, intervals |
| [q2](q2/) | Custom `vector` and `stack` (CP::vector, CP::stack) |
| [q3](q3/) | Stack, queue and heap (priority queue) |
| [q4](q4/) | Linked list and binary search tree (BST) |

Build any single file with:

```
g++ -std=c++17 file.cpp -o file
```
